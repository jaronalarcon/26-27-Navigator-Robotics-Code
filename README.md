# 26-27-Navigator-Robotics-Code

This repository contains the code that the Island Pacific Academy Navigator Robotics team developed and used during the 2026-2027 school year.

# Rules

- If you wish to create your own code for the bot, create your own file in this repository.
- If you wish to edit an existing file, commit your changes in a separate branch and start a pull request. The council will review your changes and decide how to proceed.
