# Rules and Regulations

- Every time you make a change in this repository, whether in a file or to the contents of the repository, it is required that you commit your changes to the appropriate branch and give a short description of the changes made as swiftly as possible.
- If you wish to create your own code for the bot, create your own file in the ```main``` branch of the repository.
- If you wish to edit an existing file, commit your changes in a separate branch and start a pull request. Either the file's creator or the council will review your changes and decide how to proceed.
- If someone else makes approved changes to your code, either you or the editor is responsible for ensuring that the editor's name is credited in the file where they made the change.
- All code for the bot must be in Python. C++ code will not be reviewed or used, even if someone on the team can read it.
- It is highly suggested that you put your name somewhere in the files that you make, although this is not required.
- Do not delete any files that you did not create. If you wish to delete a file, notify a councilmember and explain your rationale for deletion. The council will decide how to proceed.
- If you use generative artificial intelligence (AI) to develop or debug any of your code, please note where you used it and for what purpose you used it. We urge that you avoid using AI to write or debug any code, but we also want you to credit others' work if you choose to use it. (This rule will be revised in the future as necessary to comply with VEX's regulations on the use of AI.)
- Do not make changes to the README. Only the council can edit the README, but you may make suggestions regarding the display and contents of the README.
